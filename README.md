# Siyer Yolum

Peygamberimizin hayatını çocukluktan vefatına, ardından dört halife dönemini adım adım anlatan uygulama. Çocuk ve büyük modu, şematik haritalar, ders sonu soruları ve bölüm sınavları var.

- `www/`: uygulama (tarayıcıda `www/index.html` açılır, derleme yok)
- `www/js/data.js`: dersler, sorular, harita ve "daha fazla bilgi" içeriği
- `npm run test:smoke`: duman testi
- APK: GitHub Actions → "APK derle" (commit mesajına `[apk]` yaz ya da elle başlat)

İçerik taslaktır. Tarihler TDV İslâm Ansiklopedisi «Muhammed» maddesiyle karşılaştırıldı; yayın öncesi Diyanet yayınlarıyla da doğrulanmalı.
