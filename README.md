# Siyer Yolum

Siyeri adım adım anlatan basit uygulama prototipi. Çocuk ve büyük modu var.

- `index.html`: arayüz (derleme yok, tarayıcıda aç)
- `data.js`: 30 ders (çocuk ve büyük anlatımı, soruları) ve bölüm sınavları. İçerik Diyanet / DİA çizgisinde yazıldı, yayın öncesi kaynaklarla doğrulanmalı.

Not: örnek içerik taslaktır, yayından önce kaynaklarla doğrulanmalı.
